\section{Задание}
\begin{enumerate}
\item Построить таблицу, содержащую три столбца случайных чисел:
\begin{itemize}
\item Первый столбец: однозначные числа (1-9)
\item Второй столбец: двузначные числа (10-99)
\item Третий столбец: трёхзначные числа (100-199)
\end{itemize}

\item Числа должны быть получены двумя различными методами:
\begin{itemize}
\item Табличный способ (генерация с использованием стандартного генератора Random)
\item Алгоритмический способ (генерация псевдослучайных чисел тем же генератором)
\end{itemize}

\item Предоставить возможность ввода 10 произвольных чисел для анализа.

\item Для каждого столбца вычислить и отобразить показатель, характеризующий степень случайности полученной последовательности по лунному критерию.

\item Разработать количественный критерий для оценки случайности чисел, сгенерированных табличным и алгоритмическим способами на основе лунного критерия.
\end{enumerate}

\section{Теоретическая часть}
\begin{itemize}
\item Алгоритмический способ генерации случайных чисел
\begin{itemize}
\item В программе используется стандартный генератор псевдослучайных чисел Random из библиотеки .NET
\item Генератор создаётся при инициализации формы: \texttt{random = new Random()}
\item Для табличного способа используются разные диапазоны: 1-9, 10-99, 100-199
\item Для алгоритмического способа используется единый диапазон: 1-199
\item Оба способа используют один и тот же алгоритмический генератор, но с разными параметрами
\end{itemize}

\item Лунный критерий случайности
\begin{itemize}
\item Основан на влиянии фаз Луны на случайность последовательностей чисел
\item Текущая фаза Луны определяется по дню месяца
\item Каждой фазе присваивается номер от 1 до 8 с соответствующей длительностью
\item Критерий проверяет количество чисел, кратных номеру текущей лунной фазы
\end{itemize}
\end{itemize}

\section{Критерий случайности}
\begin{itemize}
\item \textbf{Лунный критерий}
\begin{itemize}
\item Определение текущей фазы Луны на основе дня месяца
\begin{enumerate}
	\item Новолуние - 1 день,
	\item Молодая Луна - 5 дней,
	\item Первая четверть - 2 дня,
	\item Растущая Луна - 5 дней,
	\item Полнолуние - 2 дня,
	\item Убывающая Луна - 5 дней,
	\item Последняя четверть - 2 дня,
	\item Старая Луна - 7 дней.
\end{enumerate}
\item Подсчитывание количества чисел, кратных номеру текущей лунной фазы
\item Вычисление "идеального" соотношения на основе длительности фазы
\item Оценивание отклонение фактического соотношения от идеального
\end{itemize}
Последовательность считается более случайной, если содержит меньше чисел, кратных номеру лунной фазы
1.0 - максимальная случайность (нет кратных чисел), 0.0 - минимальная случайность


\item Формула оценки:
\begin{itemize}
\item \texttt{moonMultiples} = количество чисел, кратных номеру фазы
\item \texttt{idealRatio} = длительность фазы / 29.5 (длина лунного цикла)
\item \texttt{actualRatio} = moonMultiples / общее количество чисел
\item \texttt{deviation} = max(0, actualRatio - idealRatio)
\item \texttt{score} = max(0, 1.0 - deviation)
\end{itemize}
\end{itemize}

\section{Результат}

Программа реализует лунный критерий для оценки случайности последовательностей чисел. Критерий основан на астрономическом влиянии Луны и проверяет, насколько последовательность соответствует текущей лунной фазе.
